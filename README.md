# indian-pin-public-api

### A public API for Indian PIN codes. FREE & UNLIMITED

To install dependencies:

```bash
bun install
```
or,
```bash
npm install
```
or,
```bash
yarn install
```

To run:

```bash
bun run export.ts
```

This project was created using `bun init` in bun v1.4.0. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
